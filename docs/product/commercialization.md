# Commercialization

TheLibrarian should become a professional, monetizable product without weakening its local-first safety posture.

## Positioning

Privacy-first file organization copilot for professionals and small businesses.

Primary differentiation:

- local-first default
- metadata-only provider boundary
- vertical policy packs
- dry-run planning
- rollback manifests
- managed cleanup reports

## Packaging Hypothesis

### Free Local

Current foundation.

- CLI
- local dashboard
- deterministic provider
- dry-run planning
- manual apply and rollback
- basic reports

### Pro Local

Future local product package.

- richer dashboard workflows
- advanced vertical policy packs
- professional report exports
- batch jobs
- saved presets
- improved review experience

No licensing gate exists today.

### Managed Service

Current foundation, not beta.

- operator-led dry-run sessions
- vertical pack selection
- KPI plus Markdown, JSON, and local HTML client-readable reports
- audit artifacts
- recommendations for cleanup follow-up

Apply remains a separate confirmed workflow.

### Team/Enterprise

Future architecture.

- shared templates
- centralized policy governance
- admin controls
- SSO
- billing and licensing
- support workflows
- optional metadata-only sync

None of these are implemented today.

## Upsell Path

1. User runs local dry-run with deterministic provider.
2. User opens dashboard and sees review, warnings, policy, and plan.
3. User tries vertical packs for a professional workflow.
4. Operator creates a managed cleanup report for a client or team.
5. Client asks for recurring cleanup or team templates.
6. Future Pro/Managed/Team packaging becomes relevant.

## Initial Go-To-Market

Start with service-led selling:

- law firms
- accountants and tax offices
- consultants
- marketing and creative agencies
- real estate offices
- clinics and administrative offices

Offer a low-risk directory audit: no file movement, no content upload, browser-viewable client report, and clear next steps.

## Commercial Metrics

Useful future metrics:

- managed sessions per operator
- conversion from report to paid cleanup
- average files scanned per session
- review percentage by vertical
- recurring cleanup interest
- pack adoption by industry
- time saved estimate
- support issues before apply

## Guardrails

- Do not monetize by weakening privacy.
- Do not make cloud upload mandatory.
- Do not hide safety decisions behind automation.
- Do not implement billing or authentication before the local product story is clear.
